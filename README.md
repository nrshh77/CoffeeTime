
# ☕ CoffeeTime

Навчальний вебпроєкт сайту кав'ярні CoffeeTime.

## Використані технології

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- Fetch API

## Функціональність

- Адаптивний дизайн сайту кав'ярні.
- Перемикання світлої та темної теми.
- Мобільне меню.
- Додавання карток кави.
- Контактна форма для надсилання повідомлень.
- Перевірка правильності введених даних.
- Збереження повідомлень у базі даних SQLite.
- Авторизація адміністратора.
- Перегляд повідомлень.
- Видалення повідомлень без перезавантаження сторінки.

## Встановлення та запуск

1. Встановити Node.js.
2. Відкрити папку проєкту в терміналі.
3. Встановити залежності:

   ```bash
   npm install
   ```

4. Створити файл `.env` на основі `.env.example`.
5. Вказати власний логін, пароль адміністратора та секретний ключ.
6. Запустити сервер:

   ```bash
   node server.js
   ```

7. Відкрити сайт у браузері:

   http://localhost:3000

## Вхід адміністратора

Сторінка входу:

http://localhost:3000/admin/login

Логін і пароль задаються у файлі `.env`.

## API

| Метод | Адреса | Призначення |
|---|---|---|
| POST | `/api/messages` | Надсилання повідомлення |
| GET | `/api/messages` | Отримання повідомлень (адміністратор) |
| DELETE | `/api/messages/:id` | Видалення повідомлення (адміністратор) |
| POST | `/api/auth/login` | Авторизація |
| POST | `/api/auth/logout` | Вихід |

## База даних

Для збереження повідомлень використовується SQLite.

Структура таблиці знаходиться у файлі `database/schema.sql`.

## Безпека

- Дані форми перевіряються на сервері.
- SQL-запити використовують параметризовані значення.
- Перегляд і видалення повідомлень захищені авторизацією.
- Секретні налаштування зберігаються у `.env`.
